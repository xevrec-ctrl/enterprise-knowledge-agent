# 示例科技公司 IT 支持指南

> 本文件仅用于项目演示，不代表任何真实公司的制度。

## 账号与权限

新账号由直属负责人发起申请，IT 管理员按照岗位最小权限原则开通。涉及客户数据、财务数据或生产环境的权限，需要业务负责人额外确认。员工调岗或离职时应及时回收不再需要的权限。

## 故障报修

无法登录、网络异常或办公软件故障时，应提供设备编号、发生时间、错误截图和已经尝试的处理步骤。普通问题在工作时间内四小时内响应；影响多人工作的故障应标记为高优先级，并同步直属负责人。

## 信息安全

不得在代码仓库、聊天记录或公开文档中保存 API Key、密码和客户敏感信息。测试环境应使用脱敏数据。发现密钥泄露后，应立即停用旧密钥、创建新密钥并通知 IT 管理员记录事件。
